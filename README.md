# 📄 Word Automation Using UiPath

## Project Overview
This project demonstrates Microsoft Word automation using UiPath RPA. It helps automate common Word document operations and reduces manual work.

## Features
- Read text from Word documents
- Append new text
- Replace existing words
- Insert images into Word documents
- Save Word documents
- Export Word documents to PDF

## Technologies Used
- UiPath Studio
- Robotic Process Automation (RPA)
- Microsoft Word
- XAML Workflow

## Project Files
- Main.xaml
- project.json
- project.uiproj
- entry-points.json

## How to Run
1. Download this repository.
2. Extract the project files.
3. Open UiPath Studio.
4. Open the project using project.json.
5. Restore the required dependencies.
6. Run Main.xaml.

## Project Objective
To automate Microsoft Word operations and reduce repetitive manual tasks using UiPath RPA.
